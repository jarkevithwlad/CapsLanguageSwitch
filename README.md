# Caps Language Switch

Небольшая утилита для Windows 11: перехватывает нажатие Caps Lock, отправляет сочетание Win+Space для переключения языка ввода и выключает Caps Lock, если он оказался включён.

## Использование

Скачайте `caps_language_switch.exe` из раздела **Releases** и запустите. Приложение работает в фоне без окна. Для завершения найдите его в Диспетчере задач и завершите процесс.

> Приложение устанавливает низкоуровневый перехватчик клавиатуры. Используйте только собственную собранную или проверенную версию. Для обработки клавиш в приложениях, запущенных с повышенными правами, может потребоваться запуск утилиты от администратора.

## Сборка из исходников

Требуется Rust (stable) и Cargo: https://rustup.rs

```powershell
# Отладочная сборка (с консольным окном)
cargo build

# Оптимизированная сборка без консольного окна
cargo build --release
```

Готовый релизный файл: `target/release/caps_language_switch.exe`.

Отладочный вариант выводит диагностические сообщения в консоль. Релизный вариант работает без консольного окна.
